Portaria

Registrar movimentação com token

Selecione o aluno na lista de códigos ou digite o token. A sequência entrada → saída é validada e os responsáveis vinculados são notificados.

Validação

Regras do fluxo

  1. Somente Portaria/Gestão registra presença.
  2. O token precisa corresponder a aluno ativo.
  3. Não é permitida segunda entrada sem saída.
  4. Saída exige uma entrada anterior no mesmo dia escolar.
  5. Responsável vinculado recebe notificação.
  6. A operação gera registro de auditoria.

Limitações

O que não deve ser inferido

Este MVP não é uma solução pronta para produção. Antes de usar dados reais, a instituição deve definir governança, base legal, retenção, resposta a incidentes, responsáveis pelo tratamento, infraestrutura segura, HTTPS/TLS, banco transacional, backup e avaliação de impacto quando aplicável.

A apresentação não substitui validação jurídica, segurança operacional nem autorização institucional.
