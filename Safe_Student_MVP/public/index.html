Registrar movimentação com token

Selecione o aluno na lista de códigos ou digite o token. A sequência entrada → saída é validada e os responsáveis vinculados são notificados.

Regras do fluxo

  1. Somente Portaria/Gestão registra presença.
  2. O token precisa corresponder a aluno ativo.
  3. Não é permitida segunda entrada sem saída.
  4. Saída exige uma entrada anterior no mesmo dia escolar.
  5. Responsável vinculado recebe notificação.
  6. A operação gera registro de auditoria.

Alunos

Cadastrar aluno e responsável

É obrigatório identificar um responsável no mesmo cadastro. Se o e-mail ou CPF informado já pertencer a um responsável com acesso ativo, o aluno é vinculado automaticamente à conta dele, sem gerar novo convite. Caso contrário, um código de ativação será gerado pela escola.

Responsável pelo estudante

Informar o CPF é opcional, mas ajuda a reconhecer automaticamente o mesmo responsável em matrículas futuras, mesmo que o e-mail usado seja outro. Se o responsável ainda não tiver conta, o código será mostrado apenas à gestão após o cadastro; compartilhe-o por um canal institucional conferido.

Convite de ativação criado

Copie o código e entregue ao responsável pelo canal oficial da escola. Não use dados reais neste MVP.

Editar cadastro do aluno

Vincular outro responsável

A gestão deve conferir o vínculo familiar antes de autorizar o acesso. Um e-mail ou CPF que já pertença a um responsável ativo deve usar "Pessoa que já tem acesso" abaixo.

Responsáveis cadastrados

Os responsáveis têm acesso apenas aos estudantes associados à sua conta. A gestão pode revisar e remover vínculos indevidos.

Convites pendentes

O código de ativação aparece ao gerar ou renovar um convite; não é possível consultá-lo depois.

O que não deve ser inferido

Este MVP não é uma solução pronta para produção. Antes de usar dados reais, a instituição deve definir governança, base legal, retenção, resposta a incidentes, responsáveis pelo tratamento, infraestrutura segura, HTTPS/TLS, banco transacional, backup e avaliação de impacto quando aplicável.

A apresentação não substitui validação jurídica, segurança operacional nem autorização institucional.
