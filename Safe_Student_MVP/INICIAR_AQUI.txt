SAFE STUDENT — PROJETO FUNCIONAL REVISADO

1) Abra a pasta Safe_Student_MVP no VS Code.
2) No terminal execute: npm test
3) Em seguida: npm start
4) Abra: http://localhost:3000

VERSÃO: MVP 2.1.0 | DOCUMENTAÇÃO: V2.0

GESTÃO: gestor@demo.com / demo123
PORTARIA: portaria@demo.com / demo123
RESPONSÁVEL: responsavel@demo.com / demo123

O cadastro de aluno exige um responsável no mesmo formulário. Um novo responsável recebe um código de convite mostrado à Gestão; entregue-o somente por canal institucional conferido. Na página de login, o responsável escolhe “Ative sua conta”, usa e-mail + código e visualiza os filhos vinculados.

A portaria utiliza token digitado/selecionado. Não há leitura de QR por câmera nesta versão.

A base usa dados fictícios. Não execute npm run reset sem uma cópia de segurança da base local. O MVP não é homologado para dados reais de estudantes.
