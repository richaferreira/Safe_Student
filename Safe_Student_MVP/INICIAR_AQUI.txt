SAFE STUDENT — MVP ACADÊMICO COM SQLITE

1. Instale Node.js 22.13 ou superior.
2. Abra esta pasta no VS Code.
3. Abra o terminal na raiz do projeto.
4. Execute: npm test
5. Execute: npm start
6. Abra: http://localhost:3000

cd Safe_Student_MVP

npm test

npm run db:status

npm start

NÃO É NECESSÁRIO INSTALAR SQLITE, MYSQL OU POSTGRESQL.
O banco SQLite é acessado pelo próprio Node.js.

COMANDOS ÚTEIS
npm test                 -> executa os 68 testes
npm start                -> inicia o sistema
npm run db:migrate       -> aplica migrations
npm run db:seed          -> recarrega o seed fictício
npm run db:reset         -> recria o banco de demonstração
npm run db:status        -> mostra quantidade de registros por tabela
npm run db:import-json -- caminho\db.runtime.json
                         -> importa uma base JSON antiga
