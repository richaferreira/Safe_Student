SAFE STUDENT — MVP FUNCIONAL EVOLUÍDO

1) Abra a pasta Safe_Student_MVP no VS Code.
2) No terminal execute: npm test
3) Opcionalmente execute: npm run benchmark
4) Em seguida: npm start
5) Abra: http://localhost:3000

VERSÃO EXECUTÁVEL: MVP 2.1.0 | ESPECIFICAÇÃO ACADÊMICA: V2.0

GESTÃO: gestor@demo.com / demo123
PORTARIA: portaria@demo.com / demo123
RESPONSÁVEL: responsavel@demo.com / demo123

FLUXO DE CADASTRO
- Gestão > Alunos > Novo aluno.
- Preencha aluno, adicione um ou mais responsáveis e revise antes de confirmar.
- Responsável já ativo é vinculado imediatamente.
- Pessoa sem conta recebe código de convite exibido somente à Gestão.
- Quando a pessoa ativa a conta, todos os filhos previamente vinculados aparecem automaticamente.

PORTARIA
- Localize o aluno pelo token ou use "Ler QR" quando o navegador oferecer BarcodeDetector/câmera compatível.
- O QR deve conter somente o token Safe Student (ex.: SS-...).
- O token digitado continua disponível como fallback.
- O painel mostra DENTRO*, FORA* ou SEM REGISTRO e oferece somente a próxima operação válida.
- *DENTRO/FORA é estado derivado do último registro do dia; não é rastreamento em tempo real nem frequência em sala.

SEGURANÇA/SESSÃO
- A interface usa cookie de sessão HttpOnly/SameSite.
- Para HTTPS real, configure SS_SECURE_COOKIE=1.
- A autorização continua sendo validada no servidor.
