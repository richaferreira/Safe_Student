1. VISÃO GERAL
Este documento especifica os requisitos do Safe Student, sistema web demonstrável voltado ao
controle de presença escolar e à comunicação entre escola e responsáveis. O objetivo é apresentar
uma base rastreável para implementação, testes e manutenção do MVP.
